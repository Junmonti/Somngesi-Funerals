# Somngesi Funerals Website

A responsive multi-page static website built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Pages
- `index.html` — Home
- `about.html` — About and company timeline
- `services.html` — Services
- `funeral-cover.html` — Cover information and claims documentation
- `apply.html` — Separate application enquiry form (frontend demonstration only)
- `gallery.html` — Image placeholders
- `contact.html` — Contact details, Google Maps and enquiry form

## Add photographs
Replace the placeholder SVG or placeholder blocks with approved company photographs.
Hero background is set in `css/style.css` under `.hero` and `.page-hero`.
Gallery placeholders are in `gallery.html`.
Founder and other image placeholders are in `index.html` and `about.html`.

## Important before publishing
1. The application and contact forms are frontend demonstrations only. They do not send, store or process information. Do not collect real ID numbers through the demo form.
2. Connect application handling to a secure backend before accepting personal information. Add a POPIA-compliant privacy notice and appropriate security controls.
3. Confirm what “BI” means in claims requirements and confirm the exact cover terms and waiting-period rules.
4. Confirm package vehicle allocation and social links.
5. Bank details were intentionally not published.
6. Confirm the company-approved wording for all services and cover terms.
